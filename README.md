# FormulaAI — AI-Powered Excel Tool

<img width="2240" height="1680" alt="poster-b-privacy-light" src="https://github.com/user-attachments/assets/999a47a1-f71f-42de-921d-98799bba92c4" />

Describe what you want in plain English. AI generates and edits your spreadsheets automatically.

## Features

- **Generate Tables**: Describe what you need → AI creates a complete spreadsheet
- **Edit Tables**: Upload Excel → describe changes → AI modifies → diff preview → download
- **Privacy-First**: Files are parsed locally in your browser. Never uploaded to servers.

## Try It

Visit **[formulaai.net](https://formulaai.net)**

Free tier available — no credit card required.

## Tech Stack

- Next.js + TypeScript
- DeepSeek API
- SheetJS for Excel parsing
- Supabase for auth & data
- Cloudflare Pages for hosting
